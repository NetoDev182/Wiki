Configurações

Conecte a DeepSeek, ajuste o nível de detalhe e configure opcionalmente uma pesquisa web real.

Segurança: no modo direto, a chave é mantida apenas na memória desta aba e não é salva pelo site. Uma chamada feita pelo navegador ainda pode expor a chave ao próprio navegador, extensões ou ferramentas de desenvolvimento. Para um site público, use um proxy HTTPS com a chave guardada no servidor.
O proxy deve aceitar requisições POST compatíveis com o formato de Chat Completions e manter a chave no servidor.
A chave não é gravada em localStorage ou cookies. Ela desaparece ao recarregar ou fechar esta aba. Nunca a coloque no HTML publicado.
No modo direto, use o endpoint oficial. No modo proxy, informe a URL HTTPS do seu endpoint.
Contrato esperado: POST JSON {"query":"…","limit":5}; resposta JSON {"results":[{"title":"…","url":"https://…","snippet":"…","publishedAt":"…"}]}. Use um serviço autorizado com CORS ou um proxy. Em branco = sem busca web.
Economia de créditos: consultas repetidas usam cache local; a resposta é gerada em uma chamada sempre que possível. Os limites técnicos são aproximados e a API pode truncar uma resposta muito extensa.
Remove itens deste navegador. Não altera créditos consumidos nem dados guardados por provedores externos.
